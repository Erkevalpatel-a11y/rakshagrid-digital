How integrity checking works

A cryptographic hash is a fixed-length fingerprint of a file's contents. If even one byte changes, the SHA-256 value changes completely — so comparing two hashes is a reliable way to confirm two files are identical.

Your file never leaves this browser. Hashing runs in memory using the Web Crypto API.
Requires a secure context (HTTPS or localhost). If Web Crypto is unavailable, hashing will be reported as unsupported.
